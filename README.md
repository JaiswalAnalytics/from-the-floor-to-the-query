# From the Floor to the Query

**Real business problems. Real code. One analyst who has seen both sides.**

For 3 years I ran a building-materials retail store on a paper register, with no data tools. Stock ran out at the counter.
Supplier price creep showed up months late. Slow items sat on the shelf and nobody knew how much money they held.

This series takes those problems, one per episode, and solves each with SQL, Python and Power BI.

## What is inside each episode folder

| File or folder | Purpose |
|---|---|
| `README.md` | The business problem, approach, results and limits |
| `sql/` or `python/` | The analysis code |
| `data/` | The synthetic dataset |
| `generate_data.py` | Rebuilds the dataset, so every result is reproducible |
| `cover.png` | The episode cover |

## About the data

All datasets are synthetic, built to resemble a building-materials store. None of it is copied from a real business.
